About the Project

The AI-Powered Skill Gap Analysis & Adaptive Career Roadmap System is a web-based career decision-support application designed to help students and job seekers understand their current skills and identify the skills they need for a target career.

The system compares a user's skills with the requirements of selected job roles, calculates a career readiness score, identifies skill gaps, and provides an adaptive learning roadmap.

Key Features

- User registration and login
- Job role selection
- Skill gap analysis
- Career readiness score
- Adaptive career roadmap
- Skill progress tracking
- Career recommendations
- Career simulation / What-If analysis
- Django admin management

How It Works

1. The user creates a profile and enters their skills.
2. The user selects a target job role.
3. The system compares the user's skills with the required skills for that role.
4. A career readiness score is calculated.
5. Missing and partially matched skills are identified.
6. An adaptive roadmap is generated based on skill gaps.
7. The user can update their skill progress.
8. Career simulation allows the user to explore how improving selected skills can affect their readiness score.
